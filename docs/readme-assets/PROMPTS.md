# Imágenes editoriales del README

Las cuatro imágenes principales fueron generadas específicamente para este
repositorio mediante la herramienta integrada de generación de imágenes. Son
**arte conceptual basado en los modelos del proyecto**, no capturas del visor
ni una promesa de equivalencia visual con el runtime.

Fecha de generación: 2026-08-09.

## Procesamiento

Los PNG generados se convirtieron a WebP con `ffmpeg`, manteniendo su
resolución original y aplicando calidad visual 86–88. Los archivos WebP
resultantes, incluida la captura real del visor, suman menos de 350 KiB.
